неиспользуемых элементов, объединения загрузки метаданных и удаления аргументов
запуска выгрузки. В этой сверке

разовая отправка без Bitrix24, консольные логи и диагностика 403.
Успешную разовую загрузку подтвердил пользователь; границы проверки описаны
в [разделе Google Drive](testing.md#проверки-google-drive).

Начните с [настройки](setup.md), для проверки кода используйте
[изолированные тесты](testing.md), для проверки полученного снимка —
[эксплуатационную инструкцию](operations.md#проверка-результата).
Полный перечень настроек — в [config.py](../config.py); особенности формата
и ограничения полноты — в [data.md](data.md). Каталога `wiki/` в проекте нет.
